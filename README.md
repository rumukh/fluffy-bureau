# Пушистое бюро расследований

A cozy Russian-language detective game for a child aged 8–9 and her family,
built as an offline-installable web app on the
[AEGIS engine](https://github.com/rumukh/aegis-engine).

Status: requirements baseline. Implementation is in progress toward Stage 1:
the prologue and case 1 at all three difficulty levels.
