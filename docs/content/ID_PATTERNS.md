# Правила ID контента

ID — 1–128 символов ASCII: буквы, цифры, `.`, `_`, `:`, `/`, `-`; начинается с буквы или цифры
(ограничение `@aegis/narrative`). ID никогда не переиспользуется для другого смысла.

## Реплики из сценариев PM

ID сохраняются как в сценариях (`SCRIPT_INDEX_RU.md`, раздел 2): `P…`, `C{N}-…`, `C{N}-L2-…`,
`C{N}-L3-…` (в деле 1 — `L2-…`, `L3-…`), `…-H-…` клубок, `…-R-…` ракушка, `…-L-…` лампа,
`…-F-…` семейный режим.

**Изменение текста:** ID остаётся тем же, номер редакции `rev` растёт на 1 (оригинал PM — `rev 1`).
Запись «было → стало, причина, ссылка» обязательна; журнал `CHANGELOG_RU.md` собирается из неё
автоматически. Сборка падает, если текст расходится со сценарием PM без такой записи.

**Удаление реплики** из версии (например, R04) — реплика просто не входит в пакет; запись — в решениях
нормализации этой версии.

## Новые строки (их нет в сценариях PM)

| Шаблон | Что | Пример |
|---|---|---|
| `{сцена}-B{nn}` | Подпись кнопки, варианта выбора, карточки, предмета (R06) | `C1-1-B01` «Осмотреть скамейку» |
| `{сцена}-D{nn}` | Ремарка / метка анимации (не озвучивается) | `C1-7-D03` |
| `{сцена}-N{nn}` | Новая реплика героя внутри сцены | `C2-4-N01` |
| `{дело}-H-{nn}`, `{дело}-R-{nn}` | Новые подсказки клубка и ракушки (R05) | `C1-H-01` |
| `{дело}-NB-{nn}` | «Помоги заполнить»: объяснения ✔ и указатели на улики (D03) | `C1-NB-01`, `L3-NB-04` |
| `{дело}-AX-{axis}`, `{дело}-AX-{value}` | Колонки и значения Блокнота | `C1-AX-shed` |
| `{дело}-CL-{clue}` | Название улики в Блокноте | `C1-CL-tracks` |
| `{дело}-TITLE`, `P-TITLE` | Название дела / пролога | `C1-TITLE` |
| `GL-{term}`, `GL-{term}-DEF` | Слово словарика и его карточка (читает рассказчик) | `GL-witness-DEF` |
| `ACT-C{N}-{nn}`, `ACT-C{N}-S{nn}`, `ACT-C{N}-TITLE` | Карточка «Настоящее дело», шаги и безопасность | `ACT-C1-15` |
| `UI-{key}` | Подпись интерфейса; `key` — ключ G (`hud.pause`) | `UI-hud.pause` |
| `SK-{skill}` | Название механики | `SK-tracks` |
| `NM-{speaker}` | Имя героя как озвученная подпись | `NM-kartofan` |
| `RW-{…}` | Название награды | `RW-c1-badge` |

`{сцена}` — префикс сцены из сценария (`C1-3`, `L2-4`, `C2-L3-5`), `{дело}` — `C1`, `L2`, `L3`,
`C2`, `C2-L2` и т. д. Номера идут подряд с `01` внутри своего шаблона.

## Прочие ID (не реплики)

| Что | Шаблон | Пример |
|---|---|---|
| Пакет | `prologue`, `case{NN}-l{1..3}`, `shared` | `case01-l2` |
| Сцена | ID раздела сценария; дополнительные — с суффиксом (`-HUB`, `-4S`) | `L3-4S` |
| Улика | `c{N}-{суть}` | `c1-timeline` |
| Ложный след | `rh-c{N}-{суть}` | `rh-c1-feather` |
| Мини-игра | `c{N}l{L}-{механика}`, `p{N}-{механика}` | `c1l3-scents` |
| Цели и варианты мини-игр | короткие латинские слова, стабильны (по ним A размечает зоны) | `paw-print` |
| Награда | `rw-{пакет}-{суть}` | `rw-c1-buttons-l2` |
| Факт | `fact-c{N}-{суть}` | `fact-c1-moles` |
