# Контент «Пушистого бюро расследований» (workstream C)

- [SCHEMA.md](SCHEMA.md) — формат пакетов, шагов сценария и манифеста озвучки (контракт с G и A).
- [ID_PATTERNS.md](ID_PATTERNS.md) — правила ID и редакций.
- [CHANGELOG_RU.md](CHANGELOG_RU.md) — все правки текста: было → стало, причина, ссылка (генерируется).
- [VALIDATION_REPORT.md](VALIDATION_REPORT.md) — отчёт проверки (генерируется).
- [scripts/](scripts/) — явный сценарий каждой версии для PM (генерируется).
- [FACT_SOURCES.md](FACT_SOURCES.md) — проверка фактов и источники (T18).

Сборка: `node tools/content/build.ts` (из корня). Проверка, что выходные файлы актуальны:
`node tools/content/build.ts --check`. Тесты валидатора: `npx vitest run tools/content`.

## Обязательные правки сценариев (R01–R09): Этап 1

| R | Что сделано для пролога и дела 1 |
|---|---|
| R01 | Не относится к делу 1 (дело 2, сложность 3 — в C2). |
| R02 | Не относится к делу 1 (дело 3 — в C2). |
| R03 | У коробки мэра окошко с видимым пирогом: C1-5-06, C1-6-10, L3-7-07, L3-8-04 (ред. 2). L3-7-08 «Значит, пирог никто не ел.» после правки L3-7-07 верна без изменений. Решатель проверяет, что каждое «✖» и каждое объяснение неверной версии опирается на улику, которая сама исключает значение. |
| R04 | Все три версии собраны явно, без «без изменений». На сложности 3 убрана L2-8-02. Решения нормализации — в журнале. |
| R05 | Написаны подсказки сложности 1: клубок C1-H-01…05, ракушка C1-R-01…05. |
| R06 | Все подписи кнопок, вариантов, карточек мини-игр, колонок Блокнота, наград и интерфейса имеют ID и озвучку; одинаковые записи помечены `sameAudioAs`. |
| R07 | P0-01 «новенький стажёр» → «у нас пополнение»; L3-3-01 «спасибо, что спросил» → «спасибо за вопрос». Эвристика + ручной разбор каждого флага. |
| R08 | Пометки «черновик» в файлах PM игнорируются; исходники PM не меняются. |
| R09 | Каждая механика имеет блок `[НАВЫК]`; на сложности 3 добавлены вводные «Чашки какао» и «Кто наследил?», «Лента времени» — с условной вводной. Валидатор требует блок для каждой мини-игры. |

## Допущения команды, применённые в контенте

T04 (имя — одно слово), T06 (рассказчик читает подписи, факты, словарик), T10 (карточка рецепта),
T11 (награды: пролог 5, дело 10/15/20 пуговок, сердечко за Тёпу), T18 (факты дела 1 проверены),
T22 (описания сложностей), D03 (ракушка и «помоги заполнить» по сложностям), Q11 (не больше трёх
вариантов на экране), Q16 (неверная версия бесплатна, клубок не тратится на разбор).
