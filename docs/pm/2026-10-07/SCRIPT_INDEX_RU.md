## 2. Как читать ID реплик

| Префикс | Где |
|---|---|
| `P…` | Пролог |
| `C{N}-…` | Дело N, сложность 1 |
| `C{N}-L2-…`, `C{N}-L3-…` | Дело N, сложности 2 и 3; в деле 1 — `L2-…`, `L3-…` |
| `…-H-…` | Подсказка «Клубка» |
| `…-R-…` | Подсказка «Телефона-ракушки» |
| `…-L-…` | Реплика «Лампы смелости» |
| `…-F-…` | Семейный режим «Хранитель снов» (дело 4) |

Реплики сложности 1 переиспользуются в сложностях 2–3 по своим ID. Новые записи для озвучки нужны только для реплик с префиксами L2/L3.

Общие правила текста: `{имя}` подставляется в тексте, в озвучке звучит «пушинка» (Q28); обращения к игроку — без рода (D05).

## 6. Факты «А ты знал?»

Редакционные источники — в конце каждого файла сценария. В игре ссылок нет (Q04).

| Дело | Факты |

| 2 | Сороки не тащат всё блестящее, учёные это проверили. Почтовые голуби правда носили письма. Сороки строят гнёзда с крышей из веточек. |
| 3 | Светлячки светятся холодным светом. Летучие мыши «видят ушами» — слушают эхо. Совы летают почти бесшумно. |
| 4 | Сахар помогает ягодам храниться. Барсуки проветривают подстилку. Одна барсучья нора служила семье больше 200 лет. |
| 5 | У мышей есть песни, почти все слишком высокие для нас. Одной из древних библиотек больше 2600 лет, в ней хранились глиняные таблички. В русском алфавите 33 буквы. |
| 6 | Белки забывают часть жёлудей — из них вырастают дубы. Стрелка компаса магнитная и показывает на север. Мох растёт там, где сыро; север по нему не найти. |
| 7 | Бобры строят плотины, из-за них появляются пруды. Зубы бобра растут всю жизнь. Вход в хатку бобра — под водой. |

## 9. Что нужно учесть в модели данных

- Профиль: имя, животное, цвет шарфика, шапка; флаги пройденных механик; свой световой сигнал (D22).
- Блокнот: колонки дела со стикерами ✔ ✖ ?; страницы «Тайные заметки» (3) и «Карточки-символы» (6); шифр (плакат из дела 2).
- Энциклопедия: 24 факта; Энциклопедия героев с приметами жителей (нужна в деле 8, если игрок пропустил необязательные сцены).
- Награды: значки, пуговки, сердечки, стикеры по сложностям (★, ★★, ★★★), предметы для Конторы, звания; выдача без дублей после загрузки (Q40).
