## Общие правила версий

- Разгадка та же: **Пухлик / чердак Конторы / праздник и посвящение** (Q19).
- Ребёнок ведёт дело сам, Хвостс подсказывает из ракушки — на всех сложностях.
- **Финал (C8-8…C8-14) одинаков на всех сложностях:** сюрприз шёпотом, признание Пухлика, «Клятва сыщика», Орден, тёплые слова, юбилей. Меняются только разбор ложных следов и реплики новых подозреваемых.
- Реплики сложности 1 переиспользуются по ID `C8-…`. Новые реплики имеют ID `C8-L2-…` и `C8-L3-…`.
- Новых слов нет; 3 факта — те же.
- Все реплики к игроку — без рода.

| | Сложность 1 | Сложность 2 | Сложность 3 |
|---|---|---|---|
| Таблица | 3×3×3 | 4×4×4 | 5×5×4 |
| Улик | 3 + сравнение | 3 + сравнение | 4 + сравнение |
| Приглашение | текст проявляется | место записано пуговичным шифром | шифр + карточки нужно повернуть по компасу |
| «Сравни приметы» | 3 заметки × 3 героя | 3 × 4 | 3 × 5 |
| Ромашка | чашка в комнате (Лупа) | чашка в комнате (Лупа) | только по запаху («Пары запахов») |

Мышата Шуршики — самая хитрая ловушка: они серые и тоже не спят ночью, но у них шерсть, а не перья. Решение единственное.

**Ложные следы:** как на сложности 2 + мышата («серые, ночью не спят»). Добросовестная ошибка: мышонок уверен, что пёрышко «точно мышиное».
