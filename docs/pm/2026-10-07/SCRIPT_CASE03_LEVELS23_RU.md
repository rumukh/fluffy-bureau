### C3-L3-10. Разрешение

### C3-L3-11. «Азбука огоньков»: свой привет

Четыре сигнала, как в C3-L2-9, затем:
- C3-L3-11-01 **Пухлик:** «А теперь придумай свой сигнал для города!»
- Ребёнок собирает ритм из трёх–пяти огоньков. Любой вариант принимается.
- C3-L3-11-02 **Пухлик:** «Красиво! Это будет твой сигнал, {имя}.»
- C3-L3-11-03 **Пухлик:** «Увижу его с маяка — помашу крылом.»

Остальное — C3-9-04…C3-9-08, C3-10, C3-11. Награда — стикер «Огонёк маяка ★★★». Свой сигнал сохраняется в профиле и может появиться в «Уютном деньке».

## Заметки для команды

- «Прочитай мигание» использует сигналы финала. Ребёнок на сложности 3 сначала читает урок «Привет», потом сам его передаёт — так задача и финал связаны.
- Свой сигнал ребёнка (C3-L3-11) — новое сохраняемое значение профиля. Нужно учесть в модели сохранений (Q09).
