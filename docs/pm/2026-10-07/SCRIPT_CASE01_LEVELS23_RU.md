## Общие правила версий

- Виновник, место и событие те же: **Картофан / сарай Картофана / перепутал коробки** (Q19).
- У каждой версии свой набор вариантов, улик, ложных следов и разборов ошибок (Q15).
- Реплики сложности 1, которые подходят без изменений, переиспользуются по своим ID (`C1-…`). Новые реплики имеют ID `L2-…` и `L3-…`.
- Словарик и 3 факта — те же, что на сложности 1: дело одно.
- **Смена сложности:** только между делами; внутри дела — через «Начать дело заново» (решение Q15).
- **Обучение новых механик:** реплики с пометкой `[НАВЫК]` звучат при первой встрече с механикой в профиле. На сложность 3 можно попасть, минуя сложность 2, поэтому у «Ленты времени» есть вводные реплики и там.
- **Свидетель ошибается добросовестно** (Q17): один раз на версию, сам признаёт ошибку. Для решения эта реплика не нужна.
