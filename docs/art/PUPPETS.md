# Куклы и аватар: как устроены и как пересобрать

**Версия:** 1, 8 октября 2026 года. Формат — `aegis-rig/1` и `aegis-atlas/1`
(контракт E: `docs/api/animation.md` в `rumukh/aegis-engine`, коммит `c35d3a4`).

## Что лежит в `assets/`

| Папка | Содержимое |
|---|---|
| `assets/characters/<id>/` | `<id>.rig.json`, `<id>.atlas.json`, `<id>.atlas.webp`, `base.webp` (поза покоя одним слоем — для рантайма без кукол) |
| `assets/avatar/<species>/` | то же, плюс `scarf-mask.webp` (белая маска шарфика под тонировку) |
| `assets/avatar/hats/` | шапки: `hat-detective`, `hat-beret`, `hat-flower`, `hat-acorn` |

ID героев совпадают с `speaker` из манифеста озвучки C: `khvosts`, `watsony`,
`pudding`, `tyopa`, `kartofan`, `fitilyok`, `stella`, `mouse` (мышонок в кепке) и
`mouse2` (мышка в платке). Аватары: `avatar.kitten`, `avatar.fox`, `avatar.mouse`,
`avatar.squirrel`, `avatar.puppy`.

## Части рига

| Часть | Родитель | z | Варианты |
|---|---|---|---|
| `body` | корень | 10 | `rest` |
| `scarf` (только аватар) | `body` | 15 | один кадр, `tint: {channel: "scarf"}` |
| `head` | `body` | 20 | один кадр |
| `eyes` | `head` | 21 | `open`, `half`, `closed`; у аватара ещё `happy` |
| `brows` | `head` | 22 | `neutral`, `up`, `worried` (у Картофана и Стеллы бровей нет) |
| `mouth` | `head` | 23 | `X`, `A`–`F` (G→B, H→C по контракту) |

- **Опорная точка** рига — между ступнями: нижний ряд пикселей фигуры по центру (не внешний край кадра, иначе опорная точка выходит за кадр — AEG-ANIM-0012).
- `head` вращается вокруг шеи; глаза, брови и рот — заплатки поверх головы с мягким
  краем, поэтому вращаются вместе с ней.
- **Аватар:** все пять видов имеют одинаковые ID частей, слот `hat` (родитель `head`,
  точка у макушки), канал тонировки `scarf` (по умолчанию `#c8553d`) и якорь `badge`
  на шарфике.
- `roles`: `mouth`, `eyes`, `brows`, `head`, `lookAt: head`. `expressions`: `neutral`,
  `surprised` (брови вверх), `worried`; у аватара — `happy`.
- **Масштаб:** логический пиксель = пиксель атласа (`scale: 1`), 0,6 от мастера.
  Взрослый герой — около 800 логических пикселей в сцене 2560×1600.

## Шарфик и шапки

Шарфик на основе аватара написан светло-серым. Маска шарфика получена маскированной
правкой (шарфик закрашен пурпурным только для маски) и уточнена по цвету оригинала;
в атлас идут исходные серые пиксели. Рантайм умножает их на цвет из палитры профиля.

Шапки — отдельные картинки: нижний край по центру ставится в точку слота `hat`.

## Как пересобрать

```powershell
# 1. правки лица (глаза, брови, рот) по маскам — платные вызовы Azure
python tools/assets/art/puppet.py prepare tools/assets/art/puppets/<id>.json
python tools/assets/art/gen_batch.py F:\AI\GameAssets\fluffy-bureau\puppets\<dir>\jobs_edits.json
# 2. сборка атласа и рига (бесплатно, повторяемо)
python tools/assets/art/puppet.py assemble tools/assets/art/puppets/<id>.json
# 3. проверка позы
python tools/assets/art/rig_preview.py assets/characters/<id>/<id>.rig.json out.png mouth=D eyes=half
```

Конфиги `tools/assets/art/puppets/*.json` задают линию шеи, эллипсы глаз, бровей и рта
в пикселях мастера и обрез головы для правок. Мастера и правки лежат в
`F:\AI\GameAssets\fluffy-bureau\puppets\`.

## Ограничения

- Одна поза тела (`rest`). Руки не отделены: жесты делаются наклоном и покачиванием
  тела и головы. Отдельные руки и позы — следующий шаг, если ролики этого потребуют.
- Хвостс без палочки для пузырей; пузыри — эффект `effect.bubble`.
- Маска шарфика у основания (за подбородком) местами не захватывает серый край воротника; на экране это читается как воротник туники. Улучшить можно ручной правкой маски.
