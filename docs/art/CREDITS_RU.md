# Благодарности и лицензии (материалы workstream A)

**Версия:** 2, 9 октября 2026 года (Этап 2). Для страницы «Благодарности и лицензии» в
«Родительском уголке» (T23). Внешних ссылок в игре нет, поэтому здесь только названия.
Происхождение каждого файла — в `assets/manifest.json` (поле `provenance`).

## Текст для страницы в игре

> **Иллюстрации и персонажи** созданы командой игры с помощью модели изображений
> Azure OpenAI по собственному арт-гиду. Сторонние рисунки не использовались.
>
> **Голоса** синтезированы заранее голосами Azure AI Speech (Microsoft): Светлана,
> Дмитрий, Дарья, Brandon, Steffan, Onyx, Ximena, Fable, Xiaoyou, Ada, Cora. Голоса детей и
> взрослых не записывались.
>
> **Музыка** написана командой программно: пиццикато, ксилофон, челеста и мягкое
> урчание.
>
> **Звуковые эффекты и звуки-улики** синтезированы командой с нуля. Лицензия CC0.
>
> **Интерфейс и значки** нарисованы командой. Лицензия CC0.

## Подробно

| Группа | Инструмент | Условия использования |
|---|---|---|
| Фоны, листы персонажей, куклы, предметы, карточки | Azure OpenAI, развёртывание владельца `gpt-image-2.5-sunburst`; доводка `tools/assets/art/*.py` | Результаты генерации принадлежат проекту по условиям Microsoft Product Terms. Опорные изображения — только собственные стиль-кадры и листы персонажей проекта |
| Голоса | Azure AI Speech, готовые нейронные голоса, ресурс владельца (swedencentral) | Коммерческое использование по Microsoft Product Terms для готовых голосов |
| Формы рта | события виземов Azure Speech, `tools/assets/voice/synth.py` | данные проекта |
| Музыка | `tools/assets/audio/music.py` (numpy, собственная партитура) | CC0 1.0 |
| Эффекты | `tools/assets/audio/sfx.py` (numpy, синтез) | CC0 1.0 |
| Звуки-улики и их волны | `tools/assets/audio/sound_clues.py` (numpy, синтез; SVG) | CC0 1.0 |
| Шифр, плакат шифра, полоса сигналов, узоры шарфов | `tools/assets/art/cipher_kit.py`, `raster_kit.py` (SVG, Pillow) | CC0 1.0; буквы плаката набраны шрифтом Nunito (SIL OFL 1.1), шрифт в изображение не встраивается как файл |
| Иконки, кнопки, панели, стикеры | `tools/assets/art/ui_kit.py` (SVG) | CC0 1.0 |
| Сжатие | Pillow (HPND), libwebp (BSD), FFmpeg с LAME (LGPL) — только инструменты сборки, в игру не входят | — |

Шрифты Nunito и Andika (SIL OFL 1.1) подключает и указывает workstream G (T09).

## Чего нет

- Сторонних изображений, звуков, музыки и голосов.
- Изображений реальных людей и узнаваемых персонажей других авторов.
- Подражания стилю конкретных ныне живущих художников: в запросах описаны только
  приёмы (гуашь, акварель, мягкий контур).
